# Coding Challenges in Go

My implementations of the [John Crickett Coding Challenges](https://codingchallenges.fyi/challenges/intro), written in Go.

The goal of this repository is to work through small, self-contained projects while improving my understanding of Go, systems programming, CLI applications, networking, databases, and other core software engineering concepts.

## Structure

Each challenge is kept in its own directory and contains its implementation, tests, and a README documenting the approach and learnings.

```text
├── README.md
└── challenges/

```
